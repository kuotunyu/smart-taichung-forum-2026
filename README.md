# 2026 Smart Taichung 智慧台中論壇 · 個人整理

2026 年 8 月 26 日「2026 Smart Taichung 智慧台中論壇」八個場次的**非官方個人整理與再詮釋**。
把一整天的發言、公開可查證的外部事實、整理者的跨場判讀，以及論壇沒有回答的問題，
組成一份可以快速讀懂、也可以深入查證的檔案。

單一靜態 HTML，全部 CSS 與 JavaScript 內嵌，可離線閱讀。中文預設，可切換英文。

An unofficial, independent compilation of all eight sessions of the 2026 Smart Taichung Forum
(Taichung, Taiwan, 26 August 2026): Physical AI, smart-city platforms, uncrewed vehicles and the robotics supply chain.

網址：<https://kuotunyu.github.io/smart-taichung-forum-2026/>

## 來源分層

頁面把內容性質分開標示，這是這份整理的核心：

- **講者主張**：論壇中提出的說法，不自動等同已驗證事實。
- **整理者判讀**：跨場統整與工程／治理觀點；非講者原話，也非主辦單位立場。
- 具體數字若未能另行查證，標示為「講者案例數據」或「外部報導」；仍需正式文件或後續進度才能確認的，標示為「待驗證」。
